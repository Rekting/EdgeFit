# EdgeFit Changelog

## 1.2.1.1 - 2026-08-28

- Added Safe Area enforcement for borderless fullscreen browser and video
  player windows, including YouTube and Netflix fullscreen modes.
- Corrected every visual effect direction, including diagonal movement on
  secondary monitors.
- Made Pulse fade fully to black and added configurable color controls to
  Pulse and Cascade.
- Removed visible loop pauses from Cascade, Aurora and Ocean animations.
- Prevented invalid RGB channel values from crashing Neon Sweep.
- Migrated Stable updates to the signed Windows App Installer feed.
- Shipped as one signed Stable MSIX bundle for x64 and ARM64.

## 1.2.1.0 - 2026-08-23

- Moved window adjustment work off the interface thread to keep animated
  hidden areas smooth while EdgeFit is active.
- Corrected the visible movement direction of animated effects.
- Made RGB Flow visually distinct from the continuous Rainbow effect.
- Improved Cascade quality and added Ocean Waves, Ember Flow and Comet.
- Added localized effect descriptions in every supported language.
- Expanded the direction selector so diagonal labels remain fully visible.
- Shipped as one signed Stable MSIX bundle for x64 and ARM64.
